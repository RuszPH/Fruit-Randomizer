About the project

A small game of chance for better fruit choices.

Fruit Randomizer turns a simple decision into a playful moment. Press the draw button, meet a fruit from the collection, and let probability choose what comes next.

Why it exists

There are plenty of good fruits and only so much time to choose. This website makes the choice quick, light, and a little unexpected.

How it works

Every fruit has a rarity and probability value. Each draw uses those values to select a result from the collection.

What is inside

Browse the full fruit list, discover common and rare picks, and build a small history of the fruits you draw.

What you can learn

The website uses an array of objects for educational purposes. Each object stores one fruit's details, making it easier to practice arrays, objects, loops, modules, and dynamic HTML rendering.
